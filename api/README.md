# API

## FastAPI
This project is built on (FastAPI)[https://fastapi.tiangolo.com].

## Installation
Requires uv and Python >= 3.14.
> uv sync --locked

## Start
> uv run fastapi dev

## Docs
Two automatic documentation providers are available:
1. Swagger: http://127.0.0.1:8000/docs
2. Redoc: http://127.0.0.1:8000/redoc
